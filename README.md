# Daneshjooyar Git Workflow Lab

A practical HTML and CSS website for learning Git and GitHub workflows.

## Goals
- Version control and meaningful commits
- Branching, merging and conflict resolution
- Issues, pull requests and code review
- Tags, releases and semantic versioning
- Safe recovery and repository inspection

## Branch strategy
- `main`: stable project history
- `develop`: integration
- `feature/*`: new features
- `release/*`: release preparation
- `hotfix/*`: urgent fixes
